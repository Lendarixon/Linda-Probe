# Linda Probe v1.4.4

Local Windows file search and OCR, formerly LocalDocs. Interface languages: English, Russian and Polish.

## Highlights

- Metro interface with browser-style tabs, keyboard shortcuts and session restoration.
- Search start page with recent searches and files, folder selection, filters, highlighted results and a preview panel.
- File browser with sorting, thumbnails, file operations and Recycle Bin undo.
- OCR queue with native file/folder selection and visible task statuses; photo gallery with description/example search and model downloads.
- Reorganized settings for search folders, OCR, photos/models, appearance and updates; individual and bulk task cancellation.
- Fixes for repeated file dialogs, Recycle Bin operations, file-operation journal placement and packaged-version detection for updates.
- Licensing hardening; privacy policy, terms/refund policy and third-party notices added.

Free includes filename and exact-word content search, browsing, previews and manual tags. Pro adds semantic search, OCR for scans and searchable PDFs, photo search by description/example and automatic tags. Neither edition has tariff limits on file count or processing speed.
