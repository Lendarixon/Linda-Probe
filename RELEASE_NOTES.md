# Linda Probe v1.4.9

Local Windows file search and OCR. Interface languages: English, Russian and Polish.

**What's new / Что нового / Co nowego**
- Free now shows how many scanned pages in your folders have no searchable text, and that OCR in Pro can read them. / Free показывает, сколько страниц-сканов без текста в ваших папках и что их читает OCR в Pro. / Free pokazuje, ile zeskanowanych stron bez tekstu jest w folderach i że odczyta je OCR w Pro.
- When nothing is found, Free mentions semantic search in Pro. / Если ничего не найдено, Free сообщает о поиске по смыслу в Pro. / Gdy nic nie znaleziono, Free informuje o wyszukiwaniu semantycznym w Pro.
- Fixed an oversized icon on the empty search screen and the installer licence check now matches the current licensing code. / Исправлен большой значок на экране пустого поиска, проверка ключа в установщике обновлена. / Naprawiono zbyt dużą ikonę, zaktualizowano sprawdzanie klucza w instalatorze.
