### What it is

Linda Probe, formerly LocalDocs, is a Windows app for searching local files, browsing documents and recognizing text with OCR. The interface supports English, Russian and Polish.

Neither edition has tariff limits on file count or processing speed.

Enter your purchased Probe key in the app's licence activation interface while online. Linda detector keys do not unlock Probe. Activation, device release and periodic validation require internet. Documents and images never leave your device for any cloud service. Purchased-key checks contact Polar; optional model downloads contact their download host, which sees your IP address.
