### What it is

Linda Probe, formerly LocalDocs, is a Windows app for searching local files, browsing documents and recognizing text with OCR. The interface supports English, Russian and Polish.

| Automatic tags | — | Yes |

Neither edition has tariff limits on file count or processing speed.

### Requirements

Windows 10/11 x64. Optional semantic-search and OCR models download after activation and require compatible hardware and sufficient free disk space. Model downloads require internet.

### Purchased-key activation

Enter your purchased Probe key in the app's licence activation interface while online. Linda detector keys do not unlock Probe. Activation, device release and periodic validation require internet. Polar receives the key and a Probe-specific hashed machine ID, not document contents. Windows DPAPI protects the local activation cache.

Perpetual keys keep working if validation cannot reach the network. Organization keys expire at the cached end of the paid term. Confirmed revocations lock Pro on the next successful licence check. Purchases use Polar's 3/20/200-device counter. Before uninstalling or moving an activation, use **Remove key** while online; uninstalling alone does not release it.

### Gift keys

Gift Personal keys are perpetual, signed Ed25519 vouchers verified offline. Enter the gift key in the app's licence activation interface. They are intended for one person and up to 3 devices; offline gifts have no server-side activation counter.

### Privacy

Search, indexing and OCR run locally by default. Documents are not sent to the operator. The app has no telemetry, analytics, usage statistics or crash reporting. Documents and images never leave your device for any cloud service. Purchased-key checks contact Polar; optional model downloads contact their download host, which sees your IP address. See the privacy policy for details.
